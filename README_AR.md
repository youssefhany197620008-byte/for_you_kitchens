# For You Kitchens — دليل التشغيل والنشر

المشروع يحتوي على موقع عربي متجاوب ومعه خادم Node.js لمحادثة الذكاء الاصطناعي. مفتاح الذكاء الاصطناعي محفوظ على الخادم وليس في المتصفح.

## المتطلبات
- Node.js إصدار 20 أو أحدث.
- Visual Studio Code.
- مفتاح API من OpenAI لتفعيل المساعد الذكي (مفتاح الـ API منفصل عن اشتراك ChatGPT وقد تكون له تكلفة استخدام).
- رقم هاتف وواتساب بصيغة دولية بدون علامة + أو مسافات، مثال مصر: `2010XXXXXXXX`.
- استضافة تدعم Node.js، ودومين إذا أردت عنوانًا خاصًا.

## التشغيل على جهازك
1. فك ضغط الملف وافتح مجلد `for_you_kitchens` داخل VS Code.
2. افتح Terminal من القائمة `Terminal > New Terminal`.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى ملف جديد اسمه `.env` في نفس المجلد.
   - Windows PowerShell:
     ```powershell
     Copy-Item .env.example .env
     ```
   - macOS/Linux:
     ```bash
     cp .env.example .env
     ```
5. افتح `.env` وضع القيم الحقيقية:
   - `OPENAI_API_KEY`: مفتاح API الخاص بك.
   - `OPENAI_MODEL`: موديل متاح لحسابك.
   - `SITE_PHONE`: رقم الهاتف بصيغة دولية، مثل `2010XXXXXXXX`.
   - `WHATSAPP_PHONE`: رقم واتساب بصيغة دولية، مثل `2010XXXXXXXX`.
6. شغّل:
   ```bash
   npm start
   ```
7. افتح Chrome على `http://localhost:3000`.

إذا لم تضف مفتاح API، سيعمل الموقع لكن مساعد الذكاء الاصطناعي سيرجع رسالة تفيد أنه غير مفعّل.

## قبل النشر العام
- استبدل الصور المرجعية بصور أصلية تملك حق استخدامها.
- أضف اسم النشاط القانوني، بيانات التواصل الحقيقية، مناطق الخدمة، وسياسة الخصوصية.
- أضف أسعارًا/خامات مؤكدة إلى تعليمات المساعد أو قاعدة بيانات؛ الكود الحالي يمنع المساعد من اختراع الأسعار لكنه لا يعرف مخزونك الفعلي.
- استخدم استضافة HTTPS تدعم Node.js واضبط متغيرات البيئة من لوحة الاستضافة. لا ترفع ملف `.env` أو مفتاح API إلى GitHub.
- اضبط حدود الإنفاق والتنبيهات لمفتاح API وراقب الاستخدام. محدد الطلبات في الكود حماية أولية وليس بديلًا عن حماية الاستضافة ومراقبتها.
- اختبر نموذج التواصل والمساعد على الهاتف والكمبيوتر قبل الإعلان.
- أضف سياسة خصوصية واضحة تشرح معالجة الرسائل والبيانات.

## ملاحظات مهمة
- النموذج يفتح واتساب برسالة جاهزة؛ العميل يراجعها ويرسلها بنفسه. لا يوجد نظام حفظ طلبات أو لوحة إدارة في هذه النسخة.
- الصور والأوصاف الحالية أمثلة قابلة للتعديل وليست معرض أعمال حقيقي.
- الظهور في Google لا يحدث تلقائيًا بمجرد نشر الموقع. بعد النشر، أضف الموقع إلى Google Search Console وأنشئ `sitemap.xml` و`robots.txt` حسب الدومين النهائي.
